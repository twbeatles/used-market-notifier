## ⚡ 10초 만에 이해하는 중고거래 알리미

- **무엇인가요?**  
  여러 중고거래 앱을 매번 켜서 새로고침할 필요 없이, 하나의 PC 프로그램에서 3대 마켓(당근·번개·중고나라)의 매물을 동시에 자동 감시하고 조건 일치 시 모바일 메신저(Telegram, Discord, Slack)로 즉시 푸시 알림을 전달하는 종합 모니터링 솔루션입니다.
- **누구에게 필요한가요?**  
  - 인기 중고 전자기기(맥북, 아이폰, 그래픽카드, 콘솔 등)나 한정판 상품을 최저가에 선점하려는 **스마트 구매자**
  - 특정 카테고리의 시세 변동 및 가격 인하 추이를 추적하는 **수집가 및 파워 쇼퍼**
  - 키워드 알림 개수 제한이나 광고성 알림에 지친 **모든 중고거래 이용자**
- **3단계 초간단 빠른 시작:**  
  1. [Releases](https://github.com/twbeatles/used-market-notifier/releases)에서 최신 `UsedMarketNotifier.exe` 다운로드  
  2. 프로그램 실행 후 `+ 키워드 추가`로 원하는 검색어와 가격 범위 입력  
  3. 헤더의 **▶ 모니터링 시작** 클릭 ➔ 조건 일치 매물 등록 시 알림 수신!

## 🏆 왜 '중고거래 알리미'인가요? (8대 핵심 경쟁력)

```
[3대 플랫폼 통합 모니터링] ───┐
[지능형 듀얼 엔진 (Playwright+Selenium)] ──┼──> [스마트 필터링] ──> [실시간 3채널 알림] ──> [1초 문의 템플릿]
[로컬 SQLite3 완벽한 프라이버시] ───┘         (가격/제외어/지역)     (Telegram/Discord/Slack)     (원클릭 복사)
```

1. **3대 메이저 플랫폼 통합 검색**: 당근마켓, 번개장터, 중고나라 카페를 한 화면에서 동시 모니터링
2. **지능형 이중 엔진 & 스텔스 우회**: Playwright 기반 고속 비동기 수집 + 문제 발생 시 Selenium 자동 폴백 + 15종 봇 탐지 우회 내장
3. **완벽한 로컬 프라이버시 & 무제한 키워드**: 외부 서버로 사용자 정보나 검색어가 전송되지 않고 내 PC 로컬 SQLite3에 안전하게 보관
4. **시세 추적 및 가격 인하 특별 감지**: 등록된 매물의 가격 변동 이력을 추적하여 가격이 내려갔을 때 별도 인하 알림 발송
5. **첫 사이클 폭풍 알림 방지 정책**: 첫 실행 시 기존에 등록되어 있던 수십 개의 매물이 한꺼번에 알림으로 쏟아지는 현상 방지
6. **AI 타이틀 분석 기반 자동 태깅**: 매물 제목을 분석하여 `A급`, `풀박스`, `급처`, `택포`, `직거래`, `네고가능`, `정품` 태그 자동 부여
7. **판매자 1초 문의 템플릿**: 매물 제목, 가격, 판매자 닉네임을 자동 치환하여 맞춤 문의 문구를 원클릭 생성
8. **Catppuccin Mocha 모던 UI & 시스템 트레이**: 눈이 편안한 감각적인 다크 테마, 백그라운드 트레이 최소화 모드 지원

## 🚀 빠른 시작 가이드

### 방법 1: 실행 파일(.exe) 사용 (일반 사용자)

1. [GitHub Releases](https://github.com/twbeatles/used-market-notifier/releases)에서 최신 버전의 `UsedMarketNotifier.exe`를 다운로드합니다.
2. 다운로드한 파일을 원하는 폴더로 이동 후 실행합니다.
3. 앱이 실행되면 상단 **설정 (⚙️)**에서 알림 채널(텔레그램, 디스코드 등)을 연결하고, **키워드**를 등록한 뒤 **▶ 모니터링 시작**을 누르면 끝납니다.

---

### 방법 2: 소스 코드 직접 실행 (개발자 및 파워유저)

#### 1. 저장소 클론 및 가상환경 구성
```bash
git clone https://github.com/twbeatles/used-market-notifier.git
cd used-market-notifier

# 가상환경 생성 및 활성화
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate
```

#### 2. 패키지 및 브라우저 드라이버 설치
```bash
# 필수 의존성 패키지 설치
pip install -r requirements.txt

# Playwright Chromium 런타임 설치 (필수)
python -m playwright install chromium
```
> **참고**: Selenium 폴백을 위해 Chrome 브라우저가 시스템에 설치되어 있어야 합니다. (ChromeDriver는 `webdriver-manager`가 자동 관리)

#### 3. 설정 파일 준비 및 실행
```bash
# 기본 설정 템플릿 복사 (최초 1회)
# settings.json이 없으면 실행 시 자동 생성되지만, 예시 파일을 기반으로 구성할 수 있습니다.
cp settings.example.json settings.json

# GUI 모드 실행
python main.py
```

### 1. 🔍 키워드 관리
모니터링할 검색 키워드를 등록하고 세부 옵션을 설정하는 화면입니다.

- **`+ 새 키워드 추가` / `Ctrl+N`**:
  - **키워드**: 검색할 상품명 입력 (예: `맥북 프로 M3`, `아이폰 15 Pro`)
  - **검색 플랫폼**: 당근마켓, 번개장터, 중고나라 중 원하는 플랫폼 체크
  - **가격 범위 필터**: 최소 금액과 최대 금액을 원 단위로 설정 (범위 밖 매물 자동 제외)  
    *(※ '가격협의', 'N/A' 등 가격 미기재 매물은 누락 방지를 위해 기본적으로 필터를 통과합니다)*
  - **제외 키워드**: `부품`, `고장`, `삽니다`, `케이스`, `대여` 등 쉼표(`,`)로 구분하여 원치 않는 매물 필터링
  - **지역 필터 (당근마켓)**: 특정 동/구 단위 지역명 입력 시 해당 지역 매물 우선 선별
  - **개별 알림 토글**: 수집은 계속하되 알림만 일시적으로 끄고 싶을 때 사용
  - **개별 검색 주기**: 기본 전역 주기 대신 해당 키워드만 더 짧거나 길게 설정 가능
- **키워드 일괄 관리**: 등록된 키워드 목록에서 개별 활성화/비활성화 체크박스 토글 지원

### 2. 📋 전체 매물 조회
실시간으로 수집된 모든 플랫폼의 매물을 한눈에 탐색하고 관리하는 대시보드입니다.

- **실시간 필터 바**:
  - **제목 검색 (`Ctrl+F`)**: 수집된 매물 중 특정 단어가 포함된 상품 실시간 검색
  - **플랫폼 필터**: 전체 / 당근마켓 / 번개장터 / 중고나라 별 필터링
  - **판매 상태 필터**: 전체 / 판매중 / 예약중 / 판매완료 필터링
- **매물 카드 / 테이블 정보**:
  - 썸네일 이미지, 플랫폼 뱃지, 상품명, 판매 가격, 등록/수집 시간, 판매자, 거래 지역 표시
  - **자동 태그 배지**: `✨ A급`, `📦 풀박스`, `🔥 급처`, `📮 택포` 등 시각적 배지 노출
  - **가격 변동 내역**: 가격이 수정된 매물은 이전 가격과 인하율(-15%)이 함께 표시
- **우클릭 컨텍스트 메뉴**:
  - **웹페이지 열기 (`Enter`)**: 기본 브라우저에서 해당 매물의 상세 링크 열기
  - **즐겨찾기 추가 (`F`)**: 관심 매물로 등록하고 개인 메모 작성
  - **판매자 차단**: 해당 판매자의 매물을 즉시 숨기고 이후 수집에서도 제외
  - **판매자 문의 메시지 작성**: 템플릿 기반으로 완성된 첫 연락 메시지 생성 창 호출

### 3. 📊 통계 대시보드 & 매물 비교

- **플랫폼별 매물 점유율 & 일별 수집량**:
  - 당근, 번개, 중고나라 간의 등록 비율 도넛 차트 및 일자별 수집 추이 그래프 제공
- **키워드별 시세 분석**:
  - 등록된 키워드별 **최저가 / 평균가 / 최고가** 자동 산출
  - 시세 대비 파격가로 올라온 매물을 직관적으로 확인
- **매물 1:1 다중 비교 (Compare Modal)**:
  - 여러 매물을 체크한 후 **[선택 매물 비교]**를 누르면 모달 창에서 가격, 상태, 위치, 판매자를 나란히 비교

### 안정성 보장 메커니즘
1. **첫 검색 사이클 폭풍 알림 방지**: 프로그램 시작 시 DB에 없는 대량의 기존 매물이 한꺼번에 알림으로 쏟아지는 현상을 방지하기 위해, 최초 1회 수집 데이터는 알림 없이 DB에만 등록됩니다.
2. **비동기 독립 알림 큐**: 크롤링 검색 루프가 네트워크 알림 발송 지연에 영향을 받지 않도록 별도의 비동기 큐(`asyncio.Queue`)와 전용 워커에서 알림을 처리합니다.
3. **채널별 독립 재시도**: 디스코드 전송 실패가 텔레그램이나 슬랙 발송에 영향을 주지 않으며, 실패한 채널만 지수 백오프(최대 3회)로 재시도합니다.
4. **설정 파일 자동 복구**: 예기치 않은 종료로 `settings.json`이 깨지더라도 백업 파일에서 유효한 상태를 찾아 자동 복구합니다.

## ❓ 자주 묻는 질문 & 문제 해결 (FAQ)

### Q1. "검색 결과가 0개입니다"라고 뜨며 매물이 안 잡혀요.
- **A**: 해당 플랫폼의 HTML 구조가 변경되었거나 일시적으로 IP가 제한되었을 수 있습니다.
  1. `설정 > 일반`에서 **백그라운드 모드** 체크를 해제하여 브라우저가 정상적으로 페이지를 로딩하는지 눈으로 확인해 보세요.
  2. 스크래퍼 모드가 `Playwright 우선`으로 되어 있다면 `Selenium 우선`으로 전환해 보세요.
  3. `python -m playwright install chromium` 명령어로 브라우저 바이너리가 최신인지 확인합니다.

### Q2. 텔레그램 알림이 오지 않습니다.
- **A**: 
  1. `설정 > 일반`에서 **"🔔 알림 받기"**에 체크가 되어 있는지 확인합니다.
  2. 봇 생성 후 텔레그램 채팅방에서 **`/start`**를 한 번이라도 입력해야 봇이 사용자에게 메시지를 보낼 수 있습니다.
  3. 설정 화면의 **🔔 테스트** 버튼을 눌러 에러 팝업 내용을 확인해 보세요.

### Q3. 당근마켓 지역 필터가 정확하지 않은 것 같아요.
- **A**: 당근마켓 웹 검색은 접속 위치 세션을 기반으로 결과를 제공하는 특성이 있습니다. 프로그램은 검색된 매물 텍스트에서 지역명을 정규식으로 대조하여 후처리 필터링하므로, 동 단위 정보가 명시되지 않은 매물은 누락 방지를 위해 다소 넓게 잡힐 수 있습니다.

### Q4. 오래 켜두었더니 프로그램이 무거워집니다.
- **A**: 수집된 매물이 많아지면 DB 크기가 증가합니다. `설정 > 유지보수` 탭에서 **자동 클린업**을 활성화하여 30일 이상 지난 과거 매물을 자동으로 정리하도록 설정해 주세요.
